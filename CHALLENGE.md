# GitHub Copilot Challenge: Build a CLI Adventure Game

## Challenge Summary

Build a simple choose-your-own-adventure CLI game using GitHub Copilot as your coding assistant.

## Goals

- Use Copilot to create game logic, branching scenes, and inventory handling
- Build a working MVP with multiple endings
- Keep the code readable and beginner-friendly

## MVP Features

- At least 5 story scenes
- Player choice branching
- Inventory items
- Multiple endings
- Input validation

## Suggested Run

```bash
python3 main.py
```

## Stretch ideas

- Save/load progress
- Random events
- ASCII art
- Health and score tracking
- More scenes and endings
